# Restaurant Reservation Bot

## 목적
식당 예약을 카카오톡 대화로 진행, 확인, 취소하는 상태형 봇이다.
날짜/시간/인원/예약자명/연락처/요청사항을 단계적으로 입력받아 예약을 확정한다.
같은 방에서도 사용자별로 독립된 예약을 관리한다.

## 명령어/트리거
- 명령어: `/예약`, `/식당예약`, `/예약확인`, `/예약조회`, `/예약목록`, `/예약취소`, `/예약도움말`
- 자동 트리거: 진행 중인 sender 예약 세션
- matcher: command, state_exists

## 입력
- `/예약` 또는 `/식당예약` — 예약 생성 시작
- 일반 메시지 — 진행 중인 세션의 현재 단계(date/time/people/name/phone/note/confirm)에 해당하는 값
- `취소`, `그만`, `/취소` — 진행 중인 예약 세션 취소
- `/예약확인`, `/예약조회`, `/예약목록` — 내 활성 예약 목록 확인
- `/예약취소` — 내 예약 취소 (1건이면 바로 취소, 여러 건이면 선택)
- `/예약취소 {예약번호}` — 특정 예약 바로 취소
- `/예약도움말` — 명령 안내

## 출력
- **생성 시작**: "예약 날짜를 알려주세요. 예: 오늘, 내일, 6월 25일, 2026-06-25"
- **날짜 입력 후**: "예약 시간을 알려주세요. 예: 19:00, 오후 7시"
- **시간 입력 후**: "몇 명으로 예약할까요? 최대 {n}명까지 가능합니다."
- **인원 입력 후**: "예약자 성함을 알려주세요."
- **성함 입력 후**: "연락처를 알려주세요. 예: 010-1234-5678" (또는 요청사항, requirePhone 옵션 따라)
- **연락처 입력 후**: "요청사항이 있으면 적어주세요. 없으면 '없음'이라고 입력해주세요."
- **요청사항 입력 후**: 요약 확인 메시지
- **확정**: "예약 완료: RSV-{timestamp}", 상세 내역
- **취소 완료**: "예약 취소 완료: {예약번호}", 내역
- **목록**: "현재 예약:" + 번호 목록
- **중복 감지 시**: "동일한 날짜와 시간에 이미 예약이 존재합니다."
- **세션 없음 시**: "진행 중인 예약 입력이 없거나 시간이 초과되었습니다."
- **도움말**: 명령어 목록 reply

## 옵션
| 이름 | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| maxReservations | integer | 30 | 방별 보관할 최근 예약 레코드 수 |
| listSize | integer | 5 | `/예약확인` 답장 표시 최대 수 |
| maxPeople | integer | 20 | 한 예약의 최대 인원 |
| maxNoteChars | integer | 120 | 요청사항 최대 길이 |
| requirePhone | boolean | True | 연락처 입력 필수 여부 |

## 상태
- `restaurant_reservation_session` (sender scope): 예약 생성 또는 취소 선택 중인 임시 세션. TTL 30분.
- `reservations` (room scope): 확정/취소된 예약 기록. TTL 없음 (SQLite 영속).

예약 레코드 필드: `reservationId`, `status`(active/canceled), `sender`, `date`, `time`, `people`, `name`, `phone`, `note`, `createdAt`, `updatedAt`, `canceledAt`.

## 외부 의존성
없음.

## 실패 조건
- 진행 중인 세션이 있는데 `/예약` 입력 시 "이미 진행 중" 안내
- 진행 중 세션에서 `취소`/`그만`/`중단` 입력 시 세션 종료
- 날짜를 이해하지 못하면 같은 단계 반복
- 시간 형식이 맞지 않으면 같은 단계 반복
- 인원이 범위를 벗어나면 같은 단계 반복
- 연락처 형식이 맞지 않으면 같은 단계 반복
- 확정 시 동일 sender/날짜/시간의 활성 예약이 있으면 중복 경고
- 다른 사용자의 예약번호로 취소 시도 시 무시
- 세션 만료 후 입력 시 "시간 초과" 안내
- 알 수 없는 단계는 세션 종료 후 재시작 안내
