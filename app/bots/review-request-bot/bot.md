# Review Request Bot

문서/메시지 검토 의뢰를 접수한다. 맞춤법 검사, 번역, 요약 유형을 선택할 수 있다.

## 명령어

- `/검토` — 검토 의뢰를 시작한다. 검토할 내용, 유형, 추가 요청사항을 순서대로 입력받는다.
- `/검토 내용` — 내용을 바로 지정하고 유형 선택부터 시작한다.

## 입력

- **검토할 내용**: 자유 텍스트 (5~2000자)
- **검토 유형**: 번호 또는 이름으로 선택 (1/맞춤법검사, 2/번역, 3/요약)
- **추가 요청사항**: 자유 텍스트; '없음'으로 생략 가능

## 출력

- 접수 완료 메시지: 보낸 사람, 검토 유형, 원문, 추가 요청 표시

## 옵션

없음.

## 상태

- **세션 (sender-scope, 30분 TTL)**: `review_session` — 내용, 유형, 요청사항 수집 단계

## 외부 의존성

없음. (추후 `http_post_json`으로 외부 검토 API 연동 가능)

## 실패 조건

- 검토할 내용이 5자 미만
- 유효하지 않은 검토 유형
- 진행 중인 의뢰가 있을 때 /검토 재입력
- 알 수 없는 단계가 저장된 세션
