# Random Draw Bot

## 목적
방 단위로 추첨을 생성하고, 참여자를 모은 뒤 무작위로 당첨자를 선정한다.
생성 후 5분 이내에 `/추첨 실행`하지 않으면 세션이 자동 만료된다.
추첨 실행은 생성자만 가능하다.

## 명령어/트리거
- 명령어: `/추첨 제목`, `/추첨 참여`, `/추첨 실행`
- 자동 트리거: 없음
- matcher: command

## 입력
- `/추첨 오늘 아이스크림 사드림` — 추첨 생성 (제목이 없으면 "추첨" 기본값)
- `/추첨 참여` — 현재 진행 중인 추첨에 참여
- `/추첨 실행` — 생성자만 실행 가능. 참여자 중 무작위 1명을 당첨자로 선정하고 발표

## 출력
- 생성 시: 추첨 생성 안내와 `/추첨 참여`, `/추첨 실행` 안내 메시지
- 참여 시: 참여자명과 현재 인원수 안내 (중복 참여 시 별도 메시지)
- 실행 시: 추첨 제목, 참여 인원, 무작위 당첨자 발표
- 세션 없음 시: 진행 중인 추첨이 없다는 안내
- 세션 만료 시: 진행 중인 추첨이 없다는 안내 (TTL 기반 자동 삭제)
- 실행 권한 없음 시: 생성자만 실행 가능하다는 안내

## 옵션
| 이름 | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| drawTtlMillis | integer | 300000 | 추첨 세션 TTL (기본 5분, 최소 1분 ~ 최대 10분) |

## 상태
room scope `random_draw_session`에 추첨 제목, 생성자, 생성 시각, 참여자 목록을 저장한다.
TTL 5분이 지나면 자동 삭제된다.

## 외부 의존성
없음.

## 실패 조건
- 진행 중인 추첨이 있는데 `/추첨` 입력 시 "이미 진행 중" 안내
- 세션 없이 `/추첨 참여` 또는 `/추첨 실행` 입력 시 "진행 중인 추첨 없음" 안내
- 생성자가 아닌 사용자가 `/추첨 실행` 입력 시 "생성자만 실행 가능" 안내
- 참여자 없이 `/추첨 실행` 입력 시 세션 종료 후 "참여자 없음" 안내
- 동일 사용자 중복 `/추첨 참여` 시 "이미 참여 중" 안내

## 테스트
