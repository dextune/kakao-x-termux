# Group Purchase Bot

공동구매/폼 모집을 생성하고 참여를 관리한다.

## 명령어

- `/폼생성` — 폼 생성을 시작한다. 품목, 가격, 마감일, 최소주문수량을 순서대로 입력받는다.
- `/폼참여 수량` — 지정한 수량으로 참여한다. 예: `/폼참여 2`
- `/폼변경 수량` — 내 참여 수량을 변경한다. 예: `/폼변경 3`
- `/폼취소` — 내 참여를 취소한다.
- `/폼목록` — 현재 참여 현황을 조회한다.
- `/폼마감` — 폼을 마감하고 최종 집계를 출력한다. (생성자만 가능)

## 입력

- **품목명**: 자유 텍스트 (2~100자)
- **가격**: 숫자 (100~10,000,000원)
- **마감일**: 오늘, 내일, 모레, ISO 형식 날짜; '없음'으로 마감 없음
- **최소주문수량**: 숫자 (1~1000)
- **참여/변경 수량**: 숫자 (1~1000)

## 출력

- 폼 생성 확인: 품목, 가격, 마감, 최소주문수량 표시
- 참여 완료 메시지: 참여자, 수량, 총 집계 표시
- 폼 마감 결과: 참여자별 수량/금액, 총 금액, 최소주문수량 충족 여부

## 옵션

| 키 | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| maxParticipants | integer | 50 | 최대 참여자 수 (2~200) |
| minOrderDefault | integer | 1 | 기본 최소주문수량 (1~100) |

## 상태

- **세션 (room-scope, 60분 TTL)**: `form_session` — 생성 단계별 상태
- **상태 (room-scope)**: `state` — 참여자 목록과 수량

## 외부 의존성

없음.

## 실패 조건

- 품목명 2자 미만
- 가격 범위 초과 (100원 미만, 1000만원 초과)
- 유효하지 않은 마감일
- 최소주문수량 범위 초과
- 중복 참여 (변경 명령 안내)
- 존재하지 않는 폼에서 참여/변경/취소/마감 시도
- 활성화된 폼이 있을 때 /폼생성 재입력
