# Survey Bot

방 단위로 설문을 생성하고 참여받아 결과를 집계한다.

## 명령어

- `/설문` — 설문 생성을 시작한다. 제목, 항목(여러 개), 복수선택 여부, 마감일을 순서대로 입력받는다.
- `/설문참여 번호` — 지정한 번호의 항목에 투표한다. 예: `/설문참여 1`
- `/설문참여 1 2` — 복수선택 허용 시 여러 항목에 동시 투표한다.
- `/설문결과` — 현재 투표 집계를 표시한다.

## 입력

- **제목**: 자유 텍스트 (2~80자, 옵션으로 최대 길이 변경 가능)
- **항목**: 한 줄에 하나씩 입력, 최소 2개 필요, '완료'로 마침
- **복수선택**: '네' 또는 '아니오'
- **마감일**: 오늘, 내일, 모레, 또는 ISO 형식 날짜; '없음'으로 마감 없음

## 출력

- 설문 생성 확인: 항목 목록과 번호 표시
- 투표 완료 메시지: 선택한 항목명 표시
- 결과 집계: 항목별 표 수, 백분율, 막대 그래프

## 옵션

| 키 | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| maxItems | integer | 20 | 설문 최대 항목 수 (2~50) |
| maxTitleChars | integer | 80 | 제목 최대 길이 (10~200) |

## 상태

- **세션 (room-scope, 30분 TTL)**: `survey_session` — 생성 단계별 상태와 투표 데이터 보관

## 외부 의존성

없음.

## 실패 조건

- 항목이 2개 미만일 때 '완료' 입력
- 존재하지 않는 번호로 투표
- 복수선택 불가 설문에서 여러 번호 선택
- 중복 투표 (동일 sender)
- 마감일 지난 후 투표 시도
- 진행 중인 설문이 있을 때 /설문 재입력
- 알 수 없는 단계가 저장된 세션
